# Abdelrahman Khalawy — Portfolio

My personal portfolio site: Computer Science & Information Systems student,
.NET backend developer, and AI-assisted software engineer. Built on a
customized Colorlib "Clark" (Bootstrap 4) template — static HTML/CSS/JS,
no build step.

- `index.html` — main site (About, Career Journey, AI Workflow, Services,
  Skills, Projects, Activities, Blog, Contact)
- `blog/` — long-form posts on spec-driven development, multi-tenant
  architecture, and identity design
- `css/`, `js/`, `fonts/`, `images/` — template and site assets

Live site: https://abdelrahmankhalawy.github.io/abdelrahman-Portfolio/
